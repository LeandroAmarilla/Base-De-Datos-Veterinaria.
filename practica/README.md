# Práctica

Cada alumno puede agregar acá su propia carpeta, con el formato `apellido-nombre/`, para practicar el flujo de Pull Request.

Ejemplo:

```
practica/
  gomez-maria/
    consultas-tabla.sql
    consultas-multitabla.sql
```

No es una entrega ni se corrige — es solo para practicar cómo se usa git en un caso real. No edites ni borres la carpeta de otro compañero.
